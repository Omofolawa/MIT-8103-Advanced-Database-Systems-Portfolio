**Database:** MySQL 8.0 (Portfolios 1–3, 5), MongoDB 6.0 (Portfolio 4)
**Cloud:** PlanetScale (free tier) for Portfolio 5

## Overview
This portfolio demonstrates advanced database systems concepts applied to a public library management system. It covers relational design, query optimisation, transactions/concurrency, NoSQL modelling, and cloud/distributed deployment.

## Repository Structure
- `portfolio-1-database-design/` — ER model, schema, normalisation
- `portfolio-2-query-optimisation/` — SQL queries, indexes, EXPLAIN plans
- `portfolio-3-transactions-concurrency/` — COMMIT/ROLLBACK, locking
- `portfolio-4-nosql/` — MongoDB document model
- `portfolio-5-distributed-cloud/` — PlanetScale deployment
- `final-documentation/` — 2–3 page summary

## How to Run
1. Install MySQL 8.0 and MySQL Workbench.
2. Run `portfolio-1-database-design/schema.sql` then `sample-data.sql`.
3. Follow each portfolio README.
4. For MongoDB, install MongoDB Community + Compass.
5. For cloud, follow `portfolio-5-distributed-cloud/cloud-setup.md`.
